# 📘 Usage Guide | Guia de Uso

## 🇬🇧 How to Use / 🇧🇷 Como Usar

Follow the steps below to run the CloudAI Vision project locally or in the cloud:

Siga os passos abaixo para executar o projeto CloudAI Vision localmente ou na nuvem:

1. Clone the Repository / Clone o Repositório
```bash
   git clone https://github.com/SeuUsuario/cloudai-vision.git
   cd cloudai-vision
```
2. Install Dependencies Make sure you have Python 3.8+ and install dependencies / Instale as Dependências Certifique-se de ter Python 3.8+ e instale as dependências:
```bash
pip install -r requirements.txt
```
3. Run the Application Launch the Streamlit app /  Execute o Aplicativo Inicie a aplicação Streamlit:
```bash
streamlit run app.py
```
4. Use the App / Utilize o App

    * Upload your image / Faça upload da sua imagem

    * Click "Analyze" / Clique em "Analyze"

    * View AI-powered visual analysis in real-time / Visualize a análise com IA em tempo real
